# Player3

MP3-плеер для Android в стиле Material 3.
Kotlin • Jetpack Compose • Media3 (ExoPlayer + MediaSession) • DataStore.

- Package: `com.rilelchaz.player3`
- minSdk 26 (Android 8.0), targetSdk 35

## Сборка
1. Откройте папку `Player3` в Android Studio (Koala / Ladybug или новее, JDK 17).
2. Дождитесь Gradle Sync (Android Studio сама скачает Gradle 8.9).
3. Run ▶ на телефоне или эмуляторе. APK: Build → Build APK(s).

Из терминала (если есть gradle wrapper): `./gradlew assembleDebug`.
